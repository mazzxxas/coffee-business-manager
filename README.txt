COFFEE BUSINESS MANAGER — PHONE INSTALL VERSION

This version is a Progressive Web App (PWA). It can have an icon on an Android phone home screen and open like an app.

IMPORTANT: To install it on a phone, the files must be hosted on an HTTPS website (for example GitHub Pages, Netlify, or another HTTPS host). Opening index.html directly from a Downloads folder is not enough for PWA installation.

After hosting:
1. Open the website in Chrome on the Android phone.
2. Use the Install/App install prompt if it appears, or Chrome menu > Add to Home screen / Install app.
3. The Coffee Business Manager icon will appear on the home screen.

The app still uses browser local storage, so data is stored on that phone/browser. Keep using Export backup regularly until cloud sync is added.
